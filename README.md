# 💪 FitLog — Workout Library

FitLog is a modern and responsive workout library web application designed to help users discover exercises, build their daily workout plan, and save their favorite workouts. Users can browse different exercises, view workout details, add exercises to their plan, and manage their saved workouts through a clean and user-friendly interface.

🔗 **Live Website:** https://fit-log-app-theta.vercel.app/

---

## 🚀 Project Overview

FitLog provides a simple and focused way to explore workouts and organize a daily exercise plan. The application includes workouts targeting different muscle groups such as Chest, Back, Legs, Arms, Shoulders, Core, and Full Body.

The application is designed to work smoothly across **mobile, tablet, and desktop devices**.

## ✨ Key Features

### 1. 🏋️ Workout Library

Users can browse a collection of workouts targeting different muscle groups, including:

* Chest
* Back
* Legs
* Arms
* Shoulders
* Core
* Full Body

Each workout card provides useful information such as workout name, equipment, estimated time, calories, and rating.

### 2. 📋 Create Today's Workout Plan

Users can add workouts to their personal plan and create a customized workout routine for the day.

The navigation bar also shows the current number of exercises added to the plan.

### 3. ❤️ Save Favorite Workouts

Users can save workouts that they are interested in and access them later from the **Saved** section.

This makes it easier to keep track of favorite exercises without searching for them again.

### 4. 🔎 Workout Details

Each workout has its own details page where users can explore more information about the selected exercise before adding it to their plan.

### 5. 📱 Fully Responsive Design

FitLog is designed to provide a smooth user experience across:

* 📱 Mobile devices
* 📟 Tablets
* 💻 Desktop screens

The layout, cards, navigation, buttons, images, and content adapt to different screen sizes.

---

## 📂 Main Pages

* **Home** — Browse the workout library
* **Workout Details** — View detailed information about a workout
* **My Plan** — Manage today's selected workouts
* **Saved** — View saved workouts
